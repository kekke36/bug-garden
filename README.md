# むしとりゲーム

HTML/CSS/JavaScript だけで動く、子ども向けの虫取りゲームです。

## GitHub Pages で公開する

1. このリポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** の **Source** を **GitHub Actions** に設定します。
3. `main` ブランチに変更を push すると、自動でデプロイされます。Actions タブから **Deploy to GitHub Pages** の実行状況を確認できます。

公開先は `https://kekke36.github.io/bug-garden/` です。
